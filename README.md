# MAKE IT COUNT

**MAKE IT COUNT** is a platform RPG game featuring an archer who is bound to his only arrow. To progress, it is crucial for both the archer and the arrow to stay alive. 

## Game Overview

In this game, you control an archer armed with a single arrow that possesses special properties. You must skillfully protect and utilize the arrow in combat, as you will need to retrieve it every time you shoot. If the arrow falls into the abyss or is destroyed, the player dies.

The game is available on itch.io with the following description:

*"If you’re skilled enough to survive the challenges that await you, I’ll set you free from your curse."*

Those were the last words you remember before being left with nothing but a bow and an arrow in an unknown place. Now, both the arrow and you are linked to each other. The only thing you can do now is move forward and trust your instincts. *“I don’t know why, but I believe in these words.”*

## Controls

The game can be played using keyboard controls or a DualShock controller.

### Keyboard Controls:
- **Arrow Keys**: Move the player (Left and Right) and jump (Up)
- **Z**: High attack
- **X**: Normal attack
- **C**: Low attack
- **ESC**: Pause the game
- **Enter**: Open the menu

### DualShock Controls:
- **Left Stick**: Move the player
- **Square**: High attack
- **Triangle**: Normal attack
- **Circle**: Low attack
- **Options Button**: Pause the game
- **X Button**: Open the menu
